Загрузка с Dukascopy через npx dukascopy-node Node.js CLI
Выберите параметры — команда обновится автоматически. Выполните её в терминале, получите CSV-файл и загрузите его через зону импорта выше. 
npx dukascopy-node -i eurusd -from 2020-01-01 -to 2026-09-23 -t h4 -f csv
Как это работает:
  1. Скопируйте команду и выполните её в терминале (нужен установленный Node.js).
  2. В текущей папке появится CSV с котировками (например, ./download/eurusd/eurusd-h4-bid-2020-01-01-2026-09-23.csv).
  3. Загрузите файл через зону «Импорт исторических котировок» выше.
  4. Если включена опция «Удалять бары выходных» — плоские бары (O=H=L=C) из CSV будут отброшены автоматически, и график станет непрерывным без «полок».
